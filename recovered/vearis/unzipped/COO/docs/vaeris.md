## Project Structure
NovaOps follows a microservices-based architecture with comprehensive documentation:

```
NovaOps/
├── docs/               # Documentation
├── src/               # Source code
│   ├── microservices/ # Individual service components
│   └── shared/        # Shared utilities and libraries
├── tests/             # Test suites
├── deploy/            # Deployment configurations
└── archive/           # Archived files (nothing deleted)
```
