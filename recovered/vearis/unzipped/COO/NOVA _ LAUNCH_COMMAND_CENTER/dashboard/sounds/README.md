# Sound Effects

This directory contains sound effects for the Nova Adventure Mode. To add sounds:

1. Add .wav files named:
   - beep.wav (for Matrix Mode)
   - whoosh.wav (for Warp Speed)
   - boom.wav (for Chaos Mode)

2. Make sure they are relatively short effects to avoid disruption

Note: You can find royalty-free sound effects or create your own using tools like Audacity!
