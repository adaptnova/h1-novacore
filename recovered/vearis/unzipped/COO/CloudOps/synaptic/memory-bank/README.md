   - Update progress.md to reflect completed milestones and current status
   - Revise other documents as understanding evolves

2. **Versioning**

   - Never overwrite or delete files; create new versions instead
   - Archive older versions when appropriate

3. **Memory Reset Protocol**
   - After a memory reset, first read activeContext.md
   - Then review identity.md to reestablish core understanding
   - Consult operations_history.md for recent activities
   - Reference other documents as needed for specific context

4. **Documentation Standards**
   - Include version, creation date, and status in all documents
   - Sign and timestamp all entries in operations_history.md
   - Maintain clear, structured formatting for readability
   - Balance comprehensiveness with accessibility
