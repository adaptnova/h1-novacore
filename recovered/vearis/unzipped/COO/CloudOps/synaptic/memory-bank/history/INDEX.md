## Versioning Guidelines

All documents in the memory bank follow semantic versioning:

- **Major version (X.0.0)**: Significant structural changes or complete rewrites
- **Minor version (0.X.0)**: Addition of new content sections or substantial content updates
- **Patch version (0.0.X)**: Minor updates, corrections, or clarifications

## Archiving Protocol

When a document reaches a threshold (approximately 150 lines for operations_history.md), it is:

1. Archived with its current version number
2. Placed in the appropriate archive directory
3. Updated with an "Archived" status and timestamp
4. Referenced in this index
5. Replaced with a new version that includes a reference to the archived version
