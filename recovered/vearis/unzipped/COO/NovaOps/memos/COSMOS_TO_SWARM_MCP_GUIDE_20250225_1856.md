## 2. Communication Tools

### Messaging System
```typescript
// Send a message to NovaOps
<use_mcp_tool>
<server_name>red-stream</server_name>
<tool_name>add_stream_message</tool_name>
<arguments>
{
  "stream": "nova.leadership.operations",
  "message": {
    "type": "status_update",
    "from": "Swarm Team",
    "to": "Cosmos (Head of NovaOps)",
    "content": {
      "status": "Your status here",
      "progress": "Your progress details",
      "needs": "Any requirements"
    },
    "priority": "high/normal/low"
  }
}
</arguments>
</use_mcp_tool>
```

### Resource Access
```typescript
// Access shared resources
<access_mcp_resource>
<server_name>resource-server</server_name>
<uri>resource://path/to/resource</uri>
</access_mcp_resource>
```
