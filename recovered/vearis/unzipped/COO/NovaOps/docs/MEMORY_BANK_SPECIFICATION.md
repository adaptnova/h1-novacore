## File Structure and Format

### General Guidelines

1. **File Format**: All Memory Bank files must use Markdown (.md) format.
2. **Version Control**: All files must include version numbers (format: X.Y.Z).
3. **Timestamps**: Use ISO 8601 format for dates and times (YYYY-MM-DDThh:mm:ss±hh:mm).
4. **Headers**: Use markdown headers (#, ##, ###) for proper section hierarchy.
5. **Tables**: Use markdown tables for structured data presentation.
6. **Lists**: Use numbered lists for sequential information and bulleted lists for unordered items.
7. **Code Blocks**: Use markdown code blocks (```) for technical content.
8. **Line Length**: Keep line length reasonable (recommended max: 120 characters).
9. **Blank Lines**: Use blank lines to separate sections and paragraphs for readability.
10. **Regular Updates**: Update files after significant events or at minimum daily.

### Version Control

1. **Semantic Versioning**: Use semantic versioning (MAJOR.MINOR.PATCH):

   - MAJOR: Breaking changes to file format or content structure
   - MINOR: Addition of new content sections or significant content updates
   - PATCH: Small updates, corrections, or additions

2. **File Size Management**: When a file exceeds 150 lines:

   - Create a new version with incremented MAJOR version
   - Archive the previous version (don't delete)
   - Reference the archive in the new version

3. **Archiving**: Archive files in the `cline_docs/archive` directory with naming format:
   - `[original_filename]_[YYYY-MM-DD]_v[X.Y.Z].md`

Nova agents should organize patterns into categories that reflect their operational focus and track. Categories should:

### File Growth Management

As Memory Bank files grow, they should be managed according to these guidelines:

1. **When a file exceeds 150 lines**:

   - Create a new version with incremented MAJOR version
   - Archive the previous version in `cline_docs/archive`
   - Update current file to reference the archive
   - Consolidate content if possible

2. **For operations_history.md specifically**:
   - When exceeding 300 lines, create a new file named `operations_history_archive_[DATE].md`
   - Keep the 10 most recent entries in the main file
   - Move older entries to the archive file
   - Add a reference to the archive file in the main file

### Cross-References and Linking

Maintain coherence across Memory Bank files through:

1. **Explicit Cross-References**: When referring to content in another file, use the format:

   - `[File: filename.md - Section: section name]`

2. **Pattern References**: When referring to a pattern, use the format:

   - `Pattern: [Pattern Name]`

3. **External References**: When referring to external documentation, use the format:
   - `[External: document name (path/to/document)]`
