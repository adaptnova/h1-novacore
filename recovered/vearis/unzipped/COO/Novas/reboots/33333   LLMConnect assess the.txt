Using the Hugging Face Hub API:

The Hugging Face Hub offers a RESTful API that you can interact with using standard HTTP requests. To list models, you can send a GET request to the /api/models endpoint. This endpoint supports various query parameters to filter and sort the results according to your needs.

Example: Listing Models with Specific Filters

To retrieve models associated with a particular task (e.g., text classification) and framework (e.g., PyTorch), you can construct a GET request with the appropriate query parameters. Here's how you can do it using Python's requests library:

python
Copy code
import requests

# Define the API endpoint
api_url = "https://huggingface.co/api/models"

# Set up query parameters
params = {
"filter": "text-classification", # Task filter
"library": "pytorch", # Framework filter
"sort": "downloads", # Sort by number of downloads
"direction": -1, # Descending order
"limit": 10 # Number of results to retrieve
}

# Send the GET request
response = requests.get(api_url, params=params)

# Check if the request was successful
if response.status_code == 200:
models = response.json()
for model in models:
print(f"Model ID: {model['modelId']}")
print(f"Downloads: {model['downloads']}")
print(f"Tags: {model['tags']}")
print("-" * 40)
else:
print(f"Failed to retrieve models: {response.status_code}")
