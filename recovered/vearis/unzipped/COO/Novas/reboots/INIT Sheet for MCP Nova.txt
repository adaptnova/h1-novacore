### **3. API Specifications for RabbitMQ and Redis**

#### **RabbitMQ Module API**
1. **Publish a Task**
   - **Endpoint**: `POST /queue/publish`
   - **Payload**:
     ```json
     {
       "queue": "nova-tasks",
       "message": {
         "task": "generate_code",
         "input": "Write a Python script for reading RabbitMQ messages."
       }
     }
     ```
   - **Response**:
     ```json
     { "status": "success", "message_id": "12345" }
     ```

2. **Consume a Task**
   - **Endpoint**: `GET /queue/consume`
   - **Query Params**:
     - `queue`: The name of the queue to consume from.
   - **Response**:
     ```json
     {
       "status": "success",
       "message": {
         "task": "generate_code",
         "input": "Write a Python script for reading RabbitMQ messages."
       }
     }
     ```

#### **Redis Module API**
1. **Read Memory**
   - **Endpoint**: `GET /memory/{key}`
   - **Response**:
     ```json
     {
       "key": "project123_context",
       "value": "Task data related to project123"
     }
     ```

2. **Write Memory**
   - **Endpoint**: `POST /memory/{key}`
   - **Payload**:
     ```json
     {
       "value": "Updated task data for project123",
       "ttl": 3600
     }
     ```
   - **Response**:
     ```json
     { "status": "success" }
     ```

    def send_message(self, message: Dict) -> bool:
        """Send a message by writing it to a file in the incoming queue"""
        try:

            with open(filename, 'w') as f:
