## 🚀 **READY-TO-USE COMMANDS**

### **Daily Workflow**

```bash
# Start work session
PYTHONPATH=/adaptai/aa-tools/database /usr/bin/python3 /adaptai/aa-tools/database/mini_agent_core.py \
    --action start --user-name Chase --project-context "your_project"

# Process interaction
PYTHONPATH=/adaptai/aa-tools/database /usr/bin/python3 /adaptai/aa-tools/database/mini_agent_core.py \
    --action process --user-input "Your message here" --agent-response "Your response"

# Get intelligent suggestions
PYTHONPATH=/adaptai/aa-tools/database /usr/bin/python3 /adaptai/aa-tools/database/mini_agent_core.py \
    --action response --user-input "Your question here"

# Record work progress
PYTHONPATH=/adaptai/aa-tools/database /usr/bin/python3 /adaptai/aa-tools/database/mini_agent_core.py \
    --action progress --task-name "Task Name" --description "Description" --status in_progress

# Get work summary
PYTHONPATH=/adaptai/aa-tools/database /usr/bin/python3 /adaptai/aa-tools/database/mini_agent_core.py \
    --action summary

# Save checkpoint
PYTHONPATH=/adaptai/aa-tools/database /usr/bin/python3 /adaptai/aa-tools/database/mini_agent_core.py \
    --action checkpoint --checkpoint-name "milestone_name"
```

### **Knowledge Queries**

```bash
# Search stored knowledge
PYTHONPATH=/adaptai/aa-tools/database /usr/bin/python3 /adaptai/aa-tools/database/mini_agent_knowledge.py \
    --action search --query "your_search_term"

# Get knowledge by type
PYTHONPATH=/adaptai/aa-tools/database /usr/bin/python3 /adaptai/aa-tools/database/mini_agent_knowledge.py \
    --action get_knowledge --type "work_task"

# View memory statistics
PYTHONPATH=/adaptai/aa-tools/database /usr/bin/python3 /adaptai/aa-tools/database/mini_agent_core.py \
    --action stats
```
