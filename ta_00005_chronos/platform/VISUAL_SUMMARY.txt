SERVICE RESPONSIBILITIES
════════════════════════

┌─────────────────────────────────────────────────────────────────────┐
│ SNAPSHOT SERVICE                                                      │
├─────────────────────────────────────────────────────────────────────┤
│ Purpose: Ultra-fast state restoration (<10ms)                       │
│                                                                         │
│ What it stores:                                                        │
│   • Last project/thread                                               │
│   • Recent history (bounded lists)                                    │
│   • Current working directory                                         │
│                                                                         │
│ When used:                                                             │
│   ✓ On startup - restore last state instantly                         │
│   ✓ During chat - track active context                                │
│                                                                         │
│ API:                                                                   │
│   load_snapshot(agent_id) → dict                                      │
│   save_snapshot(agent_id, snapshot)                                   │
└─────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────┐
│ EVENT STORE SERVICE                                                   │
├─────────────────────────────────────────────────────────────────────┤
│ Purpose: Complete event history with rich queries                     │
│                                                                         │
│ What it stores:                                                        │
│   • Every user message                                                │
│   • Every assistant response                                          │
│   • Every tool call                                                   │
│   • Full metadata (project, thread, cwd, timestamp)                   │
│                                                                         │
│ When used:                                                             │
│   ✓ Chat messages - append all events                                 │
│   ✓ History queries - "show me last 10 messages"                      │
│   ✓ Full-text search - "find messages about X"                        │
│                                                                         │
│ API:                                                                   │
│   append_event(event) → event_id                                      │
│   get_events(agent_id, filters) → List[events]                        │
│   search_events(query, filters) → List[events]                        │
└─────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────┐
│ GRAPH SERVICE                                                         │
├─────────────────────────────────────────────────────────────────────┤
│ Purpose: Relationship mapping and collaboration tracking              │
│                                                                         │
│ What it stores:                                                        │
│   • Agents, Projects, Threads, Workspaces as nodes                    │
│   • WORKS_ON, PARTICIPATES_IN, WORKS_IN as relationships              │
│                                                                         │
│ When used:                                                             │
│   ✓ Show connections - "what projects is nexus working on?"          │
│   ✓ Collaboration - "who else worked on this project?"                │
│   ✓ History - "nexus was here 3 days ago"                             │
│                                                                         │
│ API:                                                                   │
│   link_agent_to_project(agent_id, project_id)                         │
│   get_agent_graph(agent_id) → Graph                                   │
│   find_connected_agents(agent_id) → List[agents]                      │
└─────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────┐
│ VECTOR MEMORY SERVICE                                                 │
├─────────────────────────────────────────────────────────────────────┤
│ Purpose: Semantic search and intelligent memory retrieval             │
│                                                                         │
│ What it stores:                                                        │
│   • Text embeddings (vector representations)                          │
│   • Semantic similarity scores                                        │
│   • Metadata for retrieval                                            │
│                                                                         │
│ When used:                                                             │
│   ✓ Smart queries - "what was I working on similar to this?"         │
│   ✓ Context recall - "remind me about..."                             │
│   ✓ RAG - "answer using past conversations"                           │
│                                                                         │
│ API:                                                                   │
│   embed_and_store(text, metadata) → vector_id                         │
│   semantic_search(query, agent_id) → List[similar_events]             │
│   get_similar_events(event_id) → List[events]                         │
└─────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────┐
│ MESSAGE BUS SERVICE                                                   │
├─────────────────────────────────────────────────────────────────────┤
│ Purpose: Event streaming and pub/sub                                  │
│                                                                         │
│ What it does:                                                          │
│   • Publish events to NATS subjects                                   │
│   • Enable real-time subscriptions                                    │
│   • Async event processing                                            │
│                                                                         │
│ When used:                                                             │
│   ✓ Real-time dashboards - show live events                           │
│   ✓ Monitoring - alert on patterns                                    │
│   ✓ Integration - notify other systems                                │
│                                                                         │
│ API:                                                                   │
│   publish_event(subject, event)                                       │
│   subscribe(subject, callback)                                        │
│   stream_events(subject) → AsyncIterable[events]                      │
└─────────────────────────────────────────────────────────────────────┘
