## 🔧 Usage

### Creating New Nova Entities
1. Copy template from `novacore-identity/`
2. Replace all `{PLACEHOLDER}` values
3. Place in appropriate organizational directory
4. Create `nova.pid` file to activate
5. Deploy to GitHub repository under `adaptnova/novacore-{name}`

### Migration from /profiles/
- Only ACTIVE Novas (with `nova.pid` files) are migrated
- Organizational structure determines placement
